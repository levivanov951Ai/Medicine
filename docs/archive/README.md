# Архив

## DEVELOPER_HANDOFF_ORIGINAL_DESIGN_V1.pdf

Этот PDF — исторический оригинал Developer Handoff.
Он **не является текущим source of truth** для design tokens.

Актуальные источники:

- [`design/tokens.css`](../../design/tokens.css) — canonical design tokens;
- [`docs/DEVELOPER_HANDOFF.md`](../DEVELOPER_HANDOFF.md) — актуальный developer handoff;
- [`PROJECT_CONTEXT.md`](../../PROJECT_CONTEXT.md) — продуктовая логика.

**Не используй таблицу цветов из архивного PDF для реализации.**

Значения в ней были ориентировочными и расходятся с фактически отрисованными в финальном Design v1 по всем 16 цветовым токенам. Подробности расхождения — в [`docs/DEVELOPER_HANDOFF.md`](../DEVELOPER_HANDOFF.md), раздел 2.

Файл сохранён для истории: он фиксирует итоги UX/UI-аудита Design v1 от 2026-09-24 и остаётся полезен как описание структуры компонентов, states и responsive-поведения.
